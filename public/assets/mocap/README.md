# CMU basketball motion pack

This folder contains four BVH motion-capture clips sourced from
[`Shriinivas/cmubvh`](https://github.com/Shriinivas/cmubvh), a categorized BVH
conversion of the Carnegie Mellon University Motion Capture Database.

- `06_02.bvh` — forward basketball dribble
- `06_15.bvh` — basketball dribble and shot
- `16_01.bvh` — jump
- `102_27.bvh` — defensive side-to-side movement (used for steal/reach)

The source repository states that CMU places no restrictions on use of the
original dataset and that the BVH converter places no additional restrictions
on the conversion. The original database was funded by NSF EIA-0196217.

Source: https://github.com/Shriinivas/cmubvh
