# Basketball motion assets

These FBX clips come from RancidMilk's **Massive Library of Free 3D Character
Animations**, a game-ready conversion of the Carnegie Mellon University Motion
Capture Database retargeted to a Quaternius character rig.

The local prototype uses these FBX clips:

- `140_06.fbx` — idle
- `06_01.fbx` — walk
- `09_01.fbx` — run
- `06_02.fbx` — forward basketball dribble
- `06_06.fbx` — backward basketball dribble
- `06_08.fbx` / `06_09.fbx` — left/right sideways basketball dribbles
- `06_12.fbx` — crossover and turning dribble sequence
- `06_13.fbx` — low freestyle and between-the-legs dribble sequence
- `06_15.fbx` — dribble and shoot
- `102_10.fbx` — basketball-specific straight sprint without the ball
- `102_30.fbx` — straight offensive drive
- `102_31.fbx` / `102_32.fbx` — right/left change-of-direction drives
- `124_06.fbx` — basketball lay-up sequence used for the one-hand dunk motion
- `13_10.fbx` — upward reach motion used for the dunk upper body
- `16_01.fbx` — jump
- `16_03.fbx` — high jump used for the dunk takeoff and leg motion
- `102_27.fbx` — defensive reach used as the one-shot steal action

Matching animation-only GLB files are kept as source-format references; the
runtime uses FBX so the actions and visible character share one native skeleton.

Sources:

- https://rancidmilk.itch.io/free-character-animations
- https://mocap.cs.cmu.edu/
